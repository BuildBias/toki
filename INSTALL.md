# Installation

> **Note:** Currently, this plugin is only supported for **Claude Code**.

## Option 1: Command Line

Run the following commands in your terminal to add the marketplace and install the plugin:

```bash
claude plugin marketplace add BuildBias/toki
```
```bash
claude plugin install toki@toki
```

## Option 2: Manual (Desktop App)

You can also add the plugin manually through the Claude Code Desktop app by following these steps:

1. Navigate to **Settings**
2. Select **Customize** > **Plugins**
3. Click **Add** > **Add Marketplace**
4. Type in: `BuildBias/toki`
5. Click **Sync** and select **Add to this computer**
